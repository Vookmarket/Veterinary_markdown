# クッシング症候群（副腎皮質機能亢進症）

[カテゴリ目次](../disease_endocrine_metabolic_index.md)

## 概要

コルチゾールの過剰によって引き起こされる様々な症状をまとめた症候群。犬では比較的よく遭遇するが、猫ではやや稀である。

### 定義

コルチゾール過剰症とも呼ばれ、副腎皮質からのコルチゾール過剰分泌により引き起こされる内分泌疾患。

### 分類

1. ACTH依存性クッシング症候群（80-85%）
   - 下垂体依存性クッシング症候群（大多数）
   - 異所性ACTH症候群（稀）

2. ACTH非依存性クッシング症候群（15-20%）
   - 副腎依存性クッシング症候群（副腎腫瘍）
   - 食事誘発性クッシング症候群（稀）

3. 医原性クッシング症候群
   - 糖質コルチコイド製剤の過剰投与による

## 徴候

| 徴候 | 関連する病態 |
|------|------------|
| 多飲多尿 | - バソプレシン作用の抑制<br>- 尿比重低下（<1.020が多い）<br>- BUN低下の可能性 |
| 多食 | - コルチゾールの食欲増進作用 |
| 腹囲膨満（ポットベリー） | - 肝腫大<br>- 腹腔内脂肪蓄積<br>- 多飲多尿による膀胱拡大<br>- 腹壁筋の萎縮 |
| パンティング | - 肺のコンプライアンス低下<br>- 呼吸筋の弱化<br>- 肺高血圧 |
| 全身性高血圧・タンパク尿 | - 無治療の犬の約40-80%で高血圧<br>- UPC >0.5の症例は約18%<br>- UPC>1の症例は45% |
| 尿路感染 | - 10-50%で尿培養陽性<br>- 免疫抑制作用による<br>- 多くは下部尿路徴候を示さない（<5%） |
| 肝臓の変化 | - 肝腫大（グリコーゲン蓄積）<br>- 肝細胞の空胞変性<br>- ALT上昇（80-95%）<br>- ALP顕著な上昇（76-100%） |
| 筋肉の萎縮 | - タンパク質異化亢進による<br>- 全身の筋肉が影響を受ける |
| 皮膚症状 | - 内分泌脱毛（左右対称性）<br>- 色素沈着<br>- コメド形成<br>- 皮膚の菲薄化<br>- 創傷治癒遅延<br>- 皮膚の石灰化<br>- 膿皮症 |
| その他の症状 | - 白血球のストレスパターン<br>- 低カリウム血症<br>- 高血糖・糖尿病<br>- シュウ酸カルシウム結石<br>- 血栓症<br>- シュードミオトニア<br>- 靭帯断裂 |

## 検査・診断法・手順

### スクリーニング検査

1. 低用量デキサメサゾン抑制試験（LDDST）
   - 最も推奨される検査
   - デキサメサゾン0.01mg/kg IV投与
   - 投与前、4時間後、8時間後の採血
   - 8時間後のコルチゾール値が正常範囲まで下がらない場合に陽性

2. 尿中コルチゾール/クレアチニン比（UCCR）
   - 自宅での採尿が必要
   - ストレスの影響を避けるため3日以上空ける
   - 偽陽性に注意
   - スクリーニング検査として使用

3. ACTH刺激試験
   - 合成ACTH製剤5μg/kg以上投与
   - 投与前と60分後の採血
   - 副腎依存性では約半数が陰性

### ACTH依存性の鑑別検査

1. 内因性ACTH濃度測定
   - 最も信頼できる検査
   - 採血手技に注意が必要
   - 特殊な採血管使用
   - ACTH依存性では高値、非依存性では低値

2. 高用量デキサメサゾン抑制試験
   - デキサメサゾン0.1mg/kg IV投与
   - LDDSTで代用可能なため実施頻度は低い

3. 画像診断
   - 腹部超音波検査による副腎サイズ評価
   - 両側性腫大：下垂体依存性
   - 片側性腫大：副腎依存性

## 治療法

### 内科治療

- トリロスタンによる治療が主流
  - 副腎でのコルチゾール合成を阻害
  - 広く実施可能
  - ACTH依存性クッシング症候群では生存期間の延長が報告されている

### 外科治療

- 下垂体腫瘍の放射線治療
- 下垂体腫瘍摘出（脳外科手術）
- 副腎腫瘍摘出
- 実施可能な施設が限られる

### 予後

- ACTH依存性クッシング症候群では治療した方が生存期間が長い
- 長期的な治療管理が必要

### 飼い主様への説明

- クッシング症候群は慢性的な内分泌疾患であり、完治は難しく長期的な管理が必要
- 治療により症状の改善と生活の質の向上が期待できる
- 定期的な検査と投薬管理が必要
- 多飲多尿、食欲亢進、皮膚症状などの症状改善が期待できる
- 合併症（尿路感染、高血圧など）の管理も重要
- 治療費用と長期的な通院の必要性について説明
- 副作用や合併症の早期発見のため、異常に気付いた際は速やかに受診が必要
