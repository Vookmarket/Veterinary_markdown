# 熱中症

[カテゴリ目次](../disease_endocrine_metabolic_index.md)

## 概要

熱中症は高体温が原因で全身性の炎症反応が起き、多臓器不全にも至る重篤な疾患である。基本的に犬で発症しやすく、猫は身体がしんどければ活動をセーブするため発症しにくい。

### 定義

高体温が原因で全身性の炎症反応が起き、多臓器不全にも至るもの。意識障害（神経症状・脳症）が主な症状である。

### 分類

1. 発症要因による分類
   - 環境要因：高温多湿環境、運動、閉め切った車内
   - 個体要因：短頭種気道症候群、喉頭麻痺、気管虚脱、肥満、分厚い被毛、循環障害、認知機能不全

2. 重症度による分類
   - 軽症：意識清明、バイタル安定
   - 中等症：意識障害（沈うつ）、多臓器障害の初期徴候
   - 重症：昏睡、多臓器不全、DIC

---

## 徴候

| 症状 | 関連する病態 |
|------|--------------|
| 高体温（41℃以上） | 体温調節機能の破綻 |
| 頻脈 | 高心拍出量状態 |
| パンティング | 体温調節の代償機能 |
| 血圧低下 | 循環血液量減少、血管拡張 |
| CRT短縮（0.5秒） | 血管拡張、循環障害 |
| 意識障害 | 脳障害、脳浮腫、脳出血、低血糖 |
| 嘔吐・下痢 | 消化管粘膜障害 |
| チアノーゼ | 低酸素血症 |
| 不整脈 | 心筋障害 |

## 検査・診断法・手順

### バイタルサイン測定
- 体温：41℃以上の高体温
- 脈拍：頻脈
- 呼吸：パンティング
- 血圧：低下傾向
- CRT：短縮（0.5秒）、粘膜紅潮

### 血液検査
- Hct↑、TP↑：脱水による血液濃縮
- 高Na血症：パンティングによる水分喪失
- ALT↑、CK↑：来院後24-48時間でピーク
- 有核赤血球数↑：予後不良の指標
- BUN↑、Cre↑：循環血液量減少やAKI
- 血小板数↓：DIC
- PT、APTT↑：凝固異常
- D-ダイマー↑、FDP↑：血栓形成

### 胸部X線検査
- 肺野の異常陰影
- 肺水腫、肺出血の評価

### 心電図検査
- 不整脈（特に心室性期外収縮）の評価

### 尿量モニタリング
- 正常：2 mL/kg/時以上

## 治療法

### 体温管理
1. 冷却
   - ぬるま湯による体表冷却
   - 送風
   - 保冷剤の使用（頚部、肢の下、鼠径部）
   - 目標体温39.4℃
   - 禁忌：冷水（血管収縮を引き起こす）、アルコール（発火の危険）

2. 環境調整
   - 室温管理（26℃以下）
   - 風通しの確保
   - 日光の遮断

### 循環管理
- 晶質液による輸液療法
- 血圧モニタリング
- 尿量モニタリング
- 必要に応じて昇圧剤の使用

### 呼吸管理
- 酸素療法
- 必要に応じて挿管管理

### 脳保護
- 頭部15-30°挙上
- グルコース投与（低血糖時）
- 脳浮腫治療（マンニトール、グリセオール、高張食塩水）

### 合併症対策
- 抗菌薬投与（消化管バリア破綻時）
- 粘膜保護剤（胃潰瘍時）
- DIC対策

### 飼い主様への説明

1. 予防の重要性
   - 室温管理（26℃以下）
   - こまめな給水
   - 適切な運動量調整
   - 車内放置の禁止
   - リスク因子（短頭種、肥満等）の管理

2. 緊急時の対応
   - ぬるま湯による冷却
   - 送風
   - 速やかな病院受診

3. 予後
   - 早期発見・早期治療が重要
   - 多臓器不全やDICを合併すると予後不良
   - 基礎疾患（短頭種気道症候群等）の管理が再発予防に重要
