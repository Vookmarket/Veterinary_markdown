# 犬の感染性呼吸器疾患複合体 (Canine Infectious Respiratory Disease Complex: CIRDC)

[呼吸器疾患目次](../disease_respiratory_index.md)

## 概要

犬の感染性呼吸器疾患複合体（旧称：ケンネルコフ複合体）は、複数の病原体が関与する急性の上部呼吸器感染症です。主にシェルターや犬の集団飼育施設で問題となります。

### 定義

急性の咳を主徴とし、くしゃみや鼻および眼の分泌物を伴うことがある呼吸器感染症候群。

### 分類

1. 原因病原体による分類
   
   A. ウイルス性
   - 犬アデノウイルス2型
   - 犬ジステンパーウイルス
   - 犬呼吸器コロナウイルス
   - 犬インフルエンザウイルス
   - 犬ヘルペスウイルス
   - 犬ニューモウイルス
   - 犬パラインフルエンザウイルス

   B. 細菌性
   - Bordetella bronchiseptica
   - Streptococcus equi subsp. zooepidemicus
   - Mycoplasma spp.

2. 重症度による分類
   - 軽症（咳のみ）
   - 中等症（咳 + 鼻眼分泌物）
   - 重症（全身症状を伴う）

---

## 徴候

| 徴候 | 特徴 |
|------|------|
| 咳 | 急性発症、乾性咳嗽 |
| くしゃみ | 散発的 |
| 鼻汁 | 漿液性から粘液膿性 |
| 眼脂 | 漿液性から粘液膿性 |
| 発熱 | 重症例でみられる |
| 食欲不振 | 重症例でみられる |
| 元気消失 | 重症例でみられる |

---

## 検査・診断法・手順

### 基本検査

1. 身体検査
   - バイタルサインの確認
   - 呼吸音の聴診
   - 咳反射の評価

2. 一般的な臨床検査
   - 血液検査
   - 胸部X線検査（重症例）

### 追加検査（必要に応じて）

1. 分子診断検査
   - ウイルス性病原体のPCR検査
   - 細菌性病原体のPCR検査

2. 細菌培養・感受性試験
   - 重症例
   - 集団発生時
   - 治療反応不良例

---

## 治療法

### 軽症例（咳のみ）

- 経過観察
- 抗菌薬投与は通常不要

### 中等症・重症例

1. 抗菌薬治療の適応
   - 粘液膿性分泌物 + 発熱/食欲不振/元気消失がある場合

2. 第一選択薬
   - ドキシサイクリン
     - 用量：5 mg/kg、1日2回
     - 期間：7-10日間

3. 代替薬
   - アモキシシリン
   - アモキシシリン-クラブラン酸

### 支持療法

1. 安静
2. 加湿
3. 咳抑制（必要な場合）

### 飼い主様への説明

1. 疾病の特徴
   - 主にウイルスが原因
   - 二次的な細菌感染の可能性
   - 通常は予後良好

2. 治療について
   - 多くの場合、対症療法で改善
   - 抗菌薬投与が必要な場合の基準
   - 投与方法と期間

3. 予防
   - ワクチン接種の重要性
   - 集団飼育環境での管理
   - 感染犬との接触回避

4. モニタリング
   - 症状の観察（特に悪化の兆候）
   - 定期的な再診の必要性
