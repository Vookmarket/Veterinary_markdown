# ケンネルコフ（犬伝染性喉頭気管炎）

[呼吸器疾患目次](../disease_category_index/disease_respiratory_index.md)

## 概要

ケンネルコフは、複数の病原体が関与する犬の急性上部気道感染症で、主に密集した環境で流行する。

### 定義

犬伝染性喉頭気管炎（Infectious Tracheobronchitis）とも呼ばれ、複数の病原体による上部気道の感染症。ケンネル（犬舎）などの密集環境で感染が広がりやすい。

### 分類

原因病原体による分類：
1. 細菌性
   - ボルデテラ（Bordetella bronchiseptica）
   - マイコプラズマ（Mycoplasma cynos）

2. ウイルス性
   - 犬パラインフルエンザウイルス
   - 犬アデノウイルス2型
   - 犬ヘルペスウイルス

感染パターン：
- 単独感染
- 混合感染（ボルデテラと犬パラインフルエンザウイルスの同時感染が多い）

## 徴候

| 徴候 | 関連する病態 |
|------|--------------|
| 咳 | 気道の炎症による咳受容体の刺激 |
| 鼻汁 | 上部気道の炎症 |
| くしゃみ | 上部気道の炎症 |
| 発熱 | 感染に対する免疫反応 |
| 食欲低下 | 全身状態の悪化 |

---

## 検査・診断法・手順

### 身体検査
- 体温測定
- 呼吸状態の評価
- 気道聴診
- 気管圧迫試験（咳の誘発）
- リンパ節の触診

### 臨床検査
1. 一般検査
   - 血液検査（白血球数等）
   - 血液生化学検査

2. 病原体検査
   - PCR検査
   - 培養検査
   - 抗体検査

### 画像診断
- 胸部X線検査
  - 気管支炎のパターン
  - 肺炎の有無
  - 他の呼吸器疾患の除外

## 治療法

### 内科療法
1. 抗菌薬治療
   - ボルデテラやマイコプラズマに有効な抗菌薬
   - 二次感染予防

2. 対症療法
   - 咳止め：ブトルファノール等
   - 消炎剤：必要に応じて
   - 輸液：重症例

3. 環境管理
   - 安静
   - 清潔な環境維持
   - 加湿
   - 他の犬との接触を避ける

### 予防
- ワクチン接種
  - 鼻腔内ワクチン（ボルデテラ）
  - 混合ワクチン（各種ウイルス）
- 環境管理
  - 密集を避ける
  - 適切な換気
  - 清掃・消毒

### 予後
- 一般的に予後は良好
- 免疫不全や若齢犬では重症化のリスク
- 感染源期間：咳が治ってから3週間は菌を排出

### 飼い主様への説明

- 疾患の性質
  - 感染性疾患であること
  - 複数の病原体が関与
  - 他の犬への感染リスク

- 治療について
  - 抗菌薬の重要性
  - 安静の必要性
  - 完治までの期間

- 感染予防
  - ワクチンの重要性
  - 密集環境での注意点
  - 他の犬との接触制限

- 注意事項
  - 咳が治ってから3週間は感染源となる
  - ドッグラン等の利用制限
  - 子犬や高齢犬への感染リスク
