# 猫の上部呼吸器疾患 (Feline Upper Respiratory Tract Disease: URTD)

[呼吸器疾患目次](../disease_respiratory_index.md)

## 概要

猫の上部呼吸器疾患は、主にウイルスや細菌による感染症で、シェルターや多頭飼育環境で特に問題となる疾患群です。

### 定義

漿液性から粘液膿性の眼および鼻の分泌物、鼻出血、くしゃみ、結膜炎などの臨床症状を示す症候群。

### 分類

1. 経過による分類
   - 急性（≤10日）
   - 慢性（>10日）

2. 原因による分類
   - ウイルス性
     - ネコヘルペスウイルス1型 (FHV-1)
     - ネコカリシウイルス (FCV)
   - 細菌性（一次感染）
     - Chlamydia felis
     - Bordetella bronchiseptica
     - Streptococcus canis
     - Streptococcus equi subsp. zooepidemicus
     - Mycoplasma spp.
   - 細菌性（二次感染）
     - Staphylococcus spp.
     - Streptococcus spp.
     - Pasteurella multocida
     - E. coli
     - 嫌気性菌

## 徴候

| 徴候 | 特徴 |
|------|------|
| 鼻汁 | 漿液性から粘液膿性 |
| 眼脂 | 漿液性から粘液膿性 |
| くしゃみ | 頻発 |
| 結膜炎 | 充血、腫脹 |
| 鼻出血 | 重症例でみられる |
| 食欲不振 | 重症例でみられる |
| 発熱 | 重症例でみられる |

---

## 検査・診断法・手順

### 基本検査

1. 身体検査
   - バイタルサインの確認
   - 呼吸音の聴診
   - 口腔内、眼、鼻の視診

2. 血液検査
   - FeLV抗原検査
   - FIV抗体検査
   
### 追加検査（必要に応じて）

1. 細菌培養・感受性試験
   - 鼻腔スワブ
   - 結膜スワブ

2. PCR検査
   - FHV-1
   - FCV
   - C. felis
   - Mycoplasma spp.

## 治療法

### 急性期の治療

1. 抗ウイルス薬治療
   - ファムシクロビル
     - 適応：FHV-1感染が疑われる場合
     - 用量：40-90 mg/kg、1日2回
     - 期間：最大21日間
     - 効果：臨床症状の悪化リスクを有意に低下（プラセボ比較）
     - 注意点：
       - 投与量が少なくても効果を示す可能性あり
       - 一部の症例では21日投与でも症状が残存
       - 投与量不足による薬剤耐性に注意

2. 抗菌薬治療の適応
   - 粘液膿性分泌物 + 発熱/食欲不振/元気消失がある場合

3. 第一選択薬
   - ドキシサイクリン
     - 用量：5 mg/kg、1日2回 または 10 mg/kg、1日1回
     - 期間：7-10日間

4. 代替薬
   - アモキシシリン
   - アモキシシリン-クラブラン酸

### 慢性期の治療

1. 培養・感受性試験に基づく抗菌薬選択
2. 治療期間：臨床症状改善後1週間継続
3. 定期的な再評価（10-14日ごと）

### 支持療法

1. 加湿
2. 鼻腔洗浄（0.9%生理食塩水）
3. 食事管理（食欲低下時は温かい食事、強い香りの食事を提供）

### 飼い主様への説明

1. 疾病の特徴
   - 主にウイルスが原因
   - 二次的な細菌感染の可能性
   - 慢性化のリスク

2. 治療について
   - 抗菌薬投与の必要性
   - 投与方法と期間
   - 錠剤投与時の食道停滞防止の重要性

3. 予防
   - ワクチン接種の重要性
   - 多頭飼育環境での管理
   - ストレス軽減

4. モニタリング
   - 症状の観察
   - 定期的な再診の必要性
