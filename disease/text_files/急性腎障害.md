# 急性腎障害（AKI: Acute Kidney Injury）

[カテゴリ目次](../disease_urinary_index.md)

## 概要

急性に発症する腎臓実質の障害で、実質のダメージと機能障害の両方を含む。一時的な障害で回復可能だが、適切な治療が行われないと慢性腎臓病（CKD）に移行する可能性がある。

### 定義

急性に発症する腎臓実質の障害。腎臓の機能が急激に低下し、老廃物の排泄や電解質バランスの維持が困難となる状態。

### 分類

1. 原因部位による分類：
   - 腎前性AKI：腎臓への血流低下によるろ過障害
     - 麻酔中の低血圧
     - 重度の脱水
   - 腎性AKI：糸球体や尿細管のダメージによる障害
     - 猫のユリ中毒
     - 腎毒性のある薬物
     - 腎臓での炎症
   - 腎後性AKI：尿管、尿道などの閉塞による障害
     - 尿管閉塞
     - 尿道閉塞

2. IRISによるグレード分類：
   | グレード | クレアチニン値 (mg/dL) |
   |----------|----------------------|
   | 1        | <1.6                 |
   | 2        | 1.7-2.5             |
   | 3        | 2.6-5.0             |
   | 4        | 5.1-10.0            |
   | 5        | >10.0               |

## 徴候

| 徴候 | 関連する病態 |
|------|------------|
| 食欲不振 | 尿毒症 |
| 嘔吐 | 尿毒症、電解質異常 |
| 脱水 | 体液バランスの異常 |
| 乏尿/無尿 | 腎機能低下 |
| 徐脈 | 高K血症 |
| 不整脈 | 電解質異常（特に高K血症） |
| 意識レベル低下 | 尿毒症 |

## 検査・診断法・手順

### 血液検査
1. 腎機能検査
   - BUN
   - クレアチニン
   - リン

2. 電解質検査
   - カリウム（K）
   - ナトリウム（Na）
   - クロール（Cl）
   - カルシウム（Ca）

### 尿検査
- 比重
- 蛋白
- 沈渣
- 尿量測定

### 画像検査
- 超音波検査：腎臓の形態、尿路閉塞の有無
- X線検査：結石、腫瘍の有無

### 心電図検査
高K血症の評価：
1. テント状T波
2. P波の減高・消失
3. QRS波の幅増加・陰性化

---

## 治療法

### 原因別治療
1. 腎前性AKI
   - 輸液療法による血流改善
   - 血圧管理

2. 腎性AKI
   - 原因物質の除去
   - 支持療法

3. 腎後性AKI
   - 閉塞の解除
   - 導尿
   - 外科的処置

### 支持療法
1. 輸液療法
   - 脱水の補正
   - 電解質バランスの是正

2. 電解質異常の補正
   - 高K血症：グルコン酸Ca投与
   - その他電解質の補正

3. 栄養管理
   - 食事療法
   - 必要に応じて強制給餌

### 飼い主様への説明

1. 疾患の性質
   - 急性発症であること
   - 適切な治療で回復の可能性があること
   - CKDへの移行リスク

2. 検査の必要性
   - 定期的な血液検査
   - 尿検査
   - 心電図検査

3. 治療について
   - 入院管理の必要性
   - 輸液療法の重要性
   - 継続的なモニタリング

4. 予後
   - 早期発見・治療の重要性
   - CKDへの移行リスク
   - 定期的な経過観察の必要性

5. 予防
   - 腎毒性物質の回避
   - 適切な水分摂取
   - 定期的な健康診断
