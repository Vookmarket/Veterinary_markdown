# 膿胸

[呼吸器疾患目次](../disease_respiratory_index.md)

## 概要

膿胸は、胸腔内に細菌感染を伴う滲出液が貯留する重篤な感染性疾患です。適切な治療が行われない場合、致死的となる可能性があります。

### 定義

胸腔内に感染性の滲出液（膿）が貯留する状態。

### 分類

1. 動物種による特徴
   
   A. 猫の一般的な原因菌
   - 口腔内嫌気性菌
     - Fusobacterium
     - Prevotella
     - Porphyromonas
     - Bacteroides
     - Peptostreptococcus
     - Clostridium
     - Actinomyces
     - Filifactor villosus
   - その他の菌
     - Pasteurella spp.
     - Streptococcus spp.
     - Mycoplasma spp.

   B. 犬の一般的な原因菌
   - 嫌気性菌
     - Prevotella spp.
     - Peptostreptococcus spp.
     - Propionibacterium acnes
     - Clostridium spp.
     - Bacteroides spp.
     - Fusobacterium spp.
   - 腸内細菌科
     - E. coli
     - Klebsiella pneumoniae

2. 発症原因による分類
   - 猫：猫同士の喧嘩、上部呼吸器感染症に続発
   - 犬：異物（植物）迷入、外傷、咬傷

---

## 徴候

| 徴候 | 特徴 |
|------|------|
| 呼吸困難 | 頻呼吸、努力性呼吸 |
| 発熱 | 多くの症例でみられる |
| 食欲不振 | 全身状態の悪化を反映 |
| 元気消失 | 重症度に応じて様々 |
| 胸部聴診異常 | 呼吸音の減弱または消失 |
| 咳 | みられることがある |

---

## 検査・診断法・手順

### 基本検査

1. 身体検査
   - バイタルサインの確認
   - 呼吸状態の評価
   - 胸部聴診

2. 画像検査
   - 胸部X線検査
     - 胸水貯留像
     - 胸腔内の気体像
   - 必要に応じて超音波検査

3. 血液検査
   - 完血球計算
   - 血液生化学検査

### 胸水検査

1. 胸腔穿刺
   - 細胞診
   - 細菌培養（好気性・嫌気性）
   - 感受性試験
   - Mycoplasma培養（猫）

2. 特殊検査
   - グラム染色
   - 抗酸菌染色
   - 必要に応じて真菌培養

## 治療法

### 胸腔ドレナージ

1. 基本手技
   - 胸腔ドレーン留置
   - 持続吸引または間欠的吸引
   - 必要に応じて胸腔洗浄

2. モニタリング
   - ドレーン排液量
   - 排液性状
   - 胸部X線所見

### 抗菌薬治療

1. 初期治療（経験的治療）
   - 注射用抗菌薬の併用
     - エンロフロキサシンまたはマルボフロキサシン
     + ペニシリン系またはクリンダマイシン

2. 培養・感受性試験に基づく治療
   - 嫌気性菌への対応を考慮
   - 必要に応じて抗菌薬の変更

3. 治療期間
   - 臨床症状と画像所見に基づき判断
   - 通常3-4週間以上必要

### 支持療法

1. 輸液療法
   - 脱水の補正
   - 循環動態の維持

2. 栄養管理
   - 適切なカロリー摂取
   - 必要に応じて強制給餌

3. 疼痛管理
   - 適切な鎮痛薬の使用

### 飼い主様への説明

1. 疾病の特徴
   - 重症度と予後
   - 入院の必要性
   - 合併症のリスク

2. 治療について
   - ドレナージの重要性
   - 抗菌薬治療の必要性
   - 予想される入院期間

3. 予後
   - 早期発見・治療の重要性
   - 完治までの期間
   - 再発の可能性

4. モニタリング
   - 呼吸状態の観察
   - 体温測定
   - 食欲・活動性の評価
   - 定期的な再診
