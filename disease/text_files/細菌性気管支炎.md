# 細菌性気管支炎

[呼吸器疾患目次](../disease_respiratory_index.md)

## 概要

細菌性気管支炎は、気管支の細菌感染による炎症性疾患です。一次性の感染症として、または他の呼吸器疾患に続発して発症します。

### 定義

気管支における細菌感染により引き起こされる炎症性疾患。咳を主徴とし、呼吸困難を伴うことがある。

### 分類

1. 発症機序による分類
   - 一次性細菌性気管支炎
     - B. bronchiseptica感染症
     - Mycoplasma spp.感染症
   - 二次性細菌性気管支炎
     - 解剖学的異常（喉頭麻痺、気道虚脱など）に続発
     - アレルギー性気管支炎に続発
     - ウイルス感染後の二次感染

2. 原因菌による分類
   - 一次病原体
     - B. bronchiseptica
     - Mycoplasma spp.
   - 二次感染菌（口腔内常在菌由来）
     - Pasteurella spp.
     - Streptococcus spp.
     - Staphylococcus spp.
     - 嫌気性菌

---

## 徴候

| 徴候 | 特徴 |
|------|------|
| 咳 | 持続性、湿性または乾性 |
| 呼吸困難 | 重症例でみられる |
| 運動不耐性 | 進行例でみられる |
| 食欲不振 | 重症例でみられる |
| 発熱 | 急性期にみられることがある |

---

## 検査・診断法・手順

### 基本検査

1. 身体検査
   - バイタルサインの確認
   - 呼吸音の聴診（特に気管支音）
   - 咳反射の評価

2. 画像検査
   - 胸部X線検査
     - 気管支壁の肥厚
     - 気管支周囲のパターン
   - 必要に応じてCT検査

### 気道検査

1. 気管支鏡検査（可能な場合）
   - 気道の視覚的評価
   - 検体採取

2. 気道洗浄液検査
   - 細胞診
   - 細菌培養・感受性試験
   - Mycoplasma培養またはPCR検査

### 鑑別診断

- アレルギー性気管支炎
- 慢性気管支炎
- 気管支拡張症
- 気道異物
- 腫瘍

## 治療法

### 抗菌薬治療

1. 第一選択薬
   - ドキシサイクリン
     - 用量：5 mg/kg、1日2回
     - 期間：7-10日間（臨床反応に応じて調整）

2. 代替薬（培養・感受性試験に基づく）
   - アモキシシリン
   - アモキシシリン-クラブラン酸
   - フルオロキノロン系薬剤（重症例）

### 支持療法

1. 環境管理
   - 加湿
   - 清潔な環境維持
   - 刺激物の回避

2. 気道クリアランスの改善
   - 適度な運動
   - 必要に応じて去痰薬

### 原因疾患の管理

- 解剖学的異常の矯正（必要な場合）
- アレルギー性疾患のコントロール
- 免疫機能の評価と管理

### 飼い主様への説明

1. 疾病の特徴
   - 慢性化のリスク
   - 基礎疾患の重要性
   - 再発の可能性

2. 治療について
   - 抗菌薬投与の重要性
   - 完治までの期間
   - 再発予防の必要性

3. 予防
   - 環境管理の重要性
   - 定期的な健康診断
   - 基礎疾患のコントロール

4. モニタリング
   - 症状の観察
   - 定期的な再診の必要性
   - 悪化時の早期受診
