# 尿道閉塞（尿閉）

[カテゴリ目次](../disease_urinary_index.md)

## 概要

尿道が塞がれることにより尿が排泄できなくなる緊急性の高い疾患。特に雄猫で多く見られ、適切な治療が行われないと致死的となる可能性がある。

### 定義

尿道が何らかの原因で閉塞し、尿が排泄できなくなる状態。腎臓-尿管-膀胱-尿道の経路で尿道が閉塞すると、腎臓にも悪影響が及び、急性腎障害（AKI）を引き起こす可能性がある。

### 分類

原因による分類：
1. 猫下部尿路疾患（FLUTD）関連
   - 尿道栓子（結晶や粘液などが混ざってできる）
2. 尿道結石
3. 尿道狭窄
4. 腫瘍

---

## 徴候

| 徴候 | 関連する病態 |
|------|------------|
| 頻尿 | 膀胱の充満による刺激 |
| 排尿困難 | 尿道閉塞による通過障害 |
| 硬く大きな膀胱 | 尿の貯留による膀胱拡張 |
| 徐脈 | 高K血症による心毒性 |
| 嘔吐 | 尿毒症 |
| 食欲不振 | 全身状態の悪化 |
| 沈鬱 | 全身状態の悪化 |

---

## 検査・診断法・手順

### 身体検査
- 腹部触診：硬く大きな膀胱の触知
- バイタルサイン：徐脈の有無
- 全身状態の評価

### 血液検査
- 腎機能検査（BUN、Cre）
- 電解質検査（特にK値）
  - K > 5.5 mEq/L：高K血症
  - K > 7.5 mEq/L：生命の危険

### 心電図検査
高K血症による以下の変化を観察：
1. テント状T波
2. P波の減高・消失
3. QRS波の幅増加・陰性化
4. 不整脈の有無

### 画像検査
- X線検査：結石、腫瘍の有無
- 超音波検査：膀胱の状態、尿道の状態

---

## 治療法

### 緊急治療
1. 高K血症への対応
   - グルコン酸Ca投与（15-20分かけてゆっくりIV）
   - ECGモニタリング下で実施

2. 尿道閉塞の解除
   - 導尿
   - 必要に応じて尿道洗浄

### 支持療法
- 輸液療法
- 電解質補正
- 疼痛管理

### 原因別治療
- FLUTD：食事療法、環境改善
- 結石：外科的除去
- 腫瘍：腫瘍の種類に応じた治療

### 飼い主様への説明

1. 緊急性について
   - 尿閉は緊急性の高い状態であること
   - 特に高K血症は致死的となる可能性があること

2. 検査の必要性
   - 血液検査：腎機能、電解質
   - 心電図：心臓への影響
   - 画像検査：原因特定

3. 治療について
   - 緊急処置の必要性
   - 入院管理の可能性
   - 再発予防の重要性

4. 予後
   - 早期発見・治療で予後は比較的良好
   - 再発の可能性があること

5. 予防
   - 適切な食事管理
   - 十分な水分摂取
   - 定期的な健康診断
