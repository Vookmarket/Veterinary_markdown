# 猫喘息

[呼吸器疾患目次](../disease_category_index/disease_respiratory_index.md)

## 概要

猫の下気道疾患（FLAD）は、炎症性気管支疾患と非炎症性気管支疾患を含むすべての気管支疾患を包含する用語である。猫では、犬とは異なり咳はまれな臨床症状であり、心臓由来の咳も稀少であるため、咳は気管気管支疾患にかなり特異的である。

### 定義

猫喘息は、明らかな原因が特定できない下気道の炎症を特徴とする疾患で、アレルギー性疾患と考えられている。気道の過敏性と可逆性の気道狭窄を特徴とする。

### 分類と特徴

1. 重症度による分類：
   - 軽症：間欠的な咳のみ
   - 中等症：定期的な咳と軽度の呼吸困難
   - 重症：頻繁な咳と重度の呼吸困難（喘息発作）

2. 病態による分類：
   - 猫喘息（アレルギー性）：Tヘルパー2反応を誘導し、気道の病理学的変化を引き起こす免疫応答を特徴とする
   - 慢性気管支炎：過去の障害による気道の永久的な損傷が原因で、喘息と類似した臨床病理学的特徴を呈する二次的疾患

※現在、猫喘息と慢性気管支炎が本当に別々の病気なのか、それとも同じ病気の2つの側面なのかは不明である。

### 疫学的特徴
- 好発年齢：若年から中年齢（2〜8歳）
- 性別：雌猫に多い傾向
- 品種：シャム猫に多い傾向

## 徴候

| 徴候 | 関連する病態 | 特記事項 |
|------|--------------|----------|
| 咳 | 気道の炎症による咳受容体の刺激 | 嘔吐や毛玉を吐き出す動作と誤認されることがある |
| 喘鳴 | 気管支の収縮による気道狭窄 | 呼気相で特に顕著 |
| 呼吸困難 | 気道狭窄による換気障害 | 慢性的または徐々に進行することがある |
| 運動不耐性 | 換気障害による活動制限 | QOLの低下につながる |
| 開口呼吸 | 重度の呼吸困難時（喘息クリーゼ） | エアゾールスプレー、タバコの煙、環境中のほこり等で誘発 |
| チアノーゼ | 重度の換気障害 | 喘息クリーゼ時に出現 |

## 検査・診断法・手順

### 身体検査
注意：喘息クリーゼを起こしている猫では、過度な検査操作は禁忌である。

- 呼吸状態の評価
  - 呼吸数・呼吸パターンの評価
  - 閉塞性呼気性呼吸困難の有無
  - 頻呼吸の有無
- 聴診
  - 肺音（喘鳴音、クラックル音の確認）
  - 心音（肺の過膨張が高度な場合は減弱）
- 気管反射の評価
- 粘膜色の確認（チアノーゼの有無）

### 画像診断
1. 胸部X線検査
   - 気管支壁の肥厚（ドーナツ状または線路状）
   - 気管支間質性パターン
   - 空気閉鎖（透過性の増加および横隔膜の平坦化）
   - 右中葉の無気肺（一部の猫）
   - 注意点：
     * X線所見は診断確定の特異性に欠ける
     * 一部の猫ではX線所見が正常

2. 胸部CT検査
   - 異常所見の検出：
     * 気管支壁の肥厚
     * 斑状の肺胞パターン
     * 気管支拡張症
   - VetMousetrap（プレキシガラス製チャンバー）の利点：
     * 化学的拘束不要
     * ストレス軽減

3. 気管支内視鏡検査
   - 気道粘膜の評価（充血の有無）
   - 中程度から大量の粘液状/粘稠物質の観察
   - 気管支肺胞洗浄液（BALF）の採取
   - 注意点：
     * 犬に比べて安全性が低い
     * 気道が小さい
     * 高い気道反応性
     * 呼吸困難時は危険性増加

### 臨床検査
1. 血液検査
   - 末梢性好酸球増多：約20％（17～46％）に認められる
     * 気道の好酸球増多との相関なし
   - ストレス性白血球増加像
   - 非特異的な高グロブリン血症（14～50％）

2. BALF検査
   - 細胞割合による分類：
     * 好酸球優位：好酸球20％以上（好中球正常）または好酸球50％以上
     * 好中球優位：好中球7％以上（好酸球正常）または好中球50％以上
     * 混合性炎症：好酸球・好中球両方の増加
   - 研究による診断基準：
     * 好酸球浸潤：BALF中好酸球17％以上
     * 慢性気管支炎：BALF中好中球7％以上
     * 猫喘息：好酸球17％以上かつ好中球7％以上
   - 注意点：
     * グルココルチコイド治療により好酸球数が低下
     * 健康な猫のBALF中好酸球率は5％未満

3. 炎症性バイオマーカー
   - BALF中の測定項目：
     * インターロイキン-4
     * インターフェロン-γ
     * 腫瘍壊死因子α
     * エンドセリン-1（ET-1）：喘息診断バイオマーカーとして有望
   - 呼気凝縮液：過酸化水素（非侵襲的バイオマーカー）

4. その他の検査
   - 心虫検査：心虫関連呼吸器疾患との鑑別
   - 糞便検査：寄生虫性好酸球浸潤の除外
     * Aelurostrongylus abstrusus（Baermann法）
     * Toxocara cati（糞便浮遊法）
   - 気道反応性検査（ART）
   - アレルギー検査（必要に応じて）

## 治療法

### 内科療法
1. 環境改善
   - アレルゲンの回避（ホコリ、タバコ、スプレー類）
   - 清潔な環境維持
   - ストレス軽減
   - 加湿（必要に応じて）

2. 薬物療法
   - 気管支拡張薬
     - 吸入サルブタモール（急性期）
     - テオフィリン
     - アミノフィリン
     - テルブタリン
   - 抗炎症薬
     - 吸入ステロイド（フルティカゾン）
     - 経口ステロイド（重症例）

### 発作時の対応
- 酸素投与
- 気管支拡張薬の投与
- ストレス軽減
- 必要に応じて入院管理

### 予後
- 適切な管理で良好なQOLを維持可能
- 発作のリスクは継続
- 定期的なモニタリングが必要

### 飼い主様への説明

- 疾患の性質
  - アレルギー性の慢性疾患であること
  - 完治は難しく、長期的な管理が必要
  - 発作のリスクについて

- 日常生活での注意点
  - アレルゲンの回避方法
  - 清潔な環境維持の重要性
  - ストレス管理

- 投薬管理
  - 吸入器の使用方法
  - 定期的な投薬の重要性
  - 副作用の可能性

- 緊急時の対応
  - 発作時の対応方法
  - 夜間診療施設の確認
