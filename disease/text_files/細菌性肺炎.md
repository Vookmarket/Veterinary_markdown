# 細菌性肺炎

[呼吸器疾患目次](../disease_respiratory_index.md)

## 概要

細菌性肺炎は、肺実質の細菌感染による炎症性疾患です。一次性の感染症として、または他の疾患に続発して発症します。

### 定義

肺実質における細菌感染により引き起こされる炎症性疾患。発熱、咳、呼吸困難などを主徴とする。

### 分類

1. 発症機序による分類
   - 一次性細菌性肺炎
     - B. bronchiseptica
     - Mycoplasma spp.
     - S. equi zooepidemicus
     - S. canis
     - Y. pestis
   - 二次性細菌性肺炎
     - ウイルス感染後
     - 誤嚥性
     - 免疫不全に伴う
     - 気道疾患に続発

2. 原因菌による分類
   - 一般的な分離菌
     - E. coli
     - Pasteurella spp.
     - Streptococcus spp.
     - B. bronchiseptica
     - Enterococcus spp.
     - Mycoplasma spp.
     - S. pseudintermedius
     - Pseudomonas spp.

## 徴候

| 徴候 | 特徴 |
|------|------|
| 発熱 | 多くの症例でみられる |
| 咳 | 湿性咳嗽が一般的 |
| 呼吸困難 | 頻呼吸、努力性呼吸 |
| 食欲不振 | 全身状態の悪化を反映 |
| 元気消失 | 重症度に応じて様々 |
| 異常呼吸音 | 断続性ラ音、気管支音の増強 |

---

## 検査・診断法・手順

### 基本検査

1. 身体検査
   - バイタルサインの確認
   - 呼吸音の聴診
   - 呼吸状態の評価

2. 血液検査
   - 完血球計算
   - 血液生化学検査

3. 画像検査
   - 胸部X線検査
     - 肺胞性パターン
     - 気管支性パターン
   - 必要に応じてCT検査

### 気道検査

1. 気管支肺胞洗浄液検査
   - 細胞診
   - 細菌培養・感受性試験
   - Mycoplasma培養またはPCR検査

2. 気管支鏡検査（可能な場合）
   - 気道の視覚的評価
   - 検体採取

### 重症例での追加検査

- 血液ガス分析
- 血液培養（好気性・嫌気性）

## 治療法

### 抗菌薬治療

1. 軽症例（外来治療可能）
   - ドキシサイクリン
     - 用量：5 mg/kg、1日2回
     - 期間：臨床反応に応じて調整

2. 重症例（入院治療）
   - 注射用抗菌薬の併用
     - エンロフロキサシンまたはマルボフロキサシン
     + ペニシリン系またはクリンダマイシン

3. 治療期間
   - 最低7-10日間
   - 臨床症状改善後も1週間継続

### 支持療法

1. 輸液療法
   - 脱水の補正
   - 循環動態の維持

2. 酸素療法
   - 必要に応じて実施
   - SpO2のモニタリング

3. 去痰療法
   - 加湿
   - 気道クリアランスの促進

### 原因疾患の管理

- 誤嚥防止
- 免疫機能の評価と管理
- 基礎疾患の治療

### 飼い主様への説明

1. 疾病の特徴
   - 重症度と予後
   - 入院の必要性の判断
   - 合併症のリスク

2. 治療について
   - 抗菌薬投与の重要性
   - 治療期間
   - 予想される経過

3. 予防
   - 誤嚥防止
   - 免疫機能の維持
   - 基礎疾患の管理

4. モニタリング
   - 呼吸状態の観察
   - 体温測定
   - 食欲・活動性の評価
   - 定期的な再診
