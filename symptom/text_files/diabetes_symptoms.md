# 糖尿病関連症状

[徴候目次](../index_symptom.md)

## 定義

糖尿病に関連して発現する一連の臨床症状。インスリンの分泌不全または作用不全による高血糖に起因する症状群。

---

## 特徴

- 多飲多尿が特徴的な初期症状
- 体重減少と食欲亢進の組み合わせが特徴的
- 未治療例では重度の代謝異常に進行
- 犬では白内障が高頻度で発症
- 猫では後肢の姿勢異常（足底歩行）が特徴的
- 重症例では糖尿病性ケトアシドーシスに進行

---

## 鑑別疾患

| 症状 | 鑑別疾患 |
|------|---------|
| 多飲多尿 | クッシング症候群、腎不全、肝不全、副腎皮質機能低下症 |
| 体重減少 | 甲状腺機能亢進症、消化器疾患、悪性腫瘍 |
| 食欲亢進 | クッシング症候群、甲状腺機能亢進症、消化吸収障害 |
| 白内障（犬） | 加齢性変化、遺伝性疾患 |
| 後肢姿勢異常（猫） | 神経疾患、整形外科疾患 |
| 嘔吐 | 消化器疾患、腎不全、肝不全、膵炎 |

---

## 問診

- 「最近、水をよく飲むようになりました」
- 「トイレの回数が増えました」
- 「食欲はあるのに痩せてきています」
- 「尿の量が明らかに増えています」
- 「目が白く濁ってきました」（犬）
- 「後ろ足の付き方が変です」（猫）

---

## 検査

### 身体検査

- 体重測定（経時的変化の確認）
- 体型スコアの評価
- 脱水の評価
- 眼科検査（特に犬）
- 神経学的検査（特に猫）
- 口腔内検査（歯肉炎、歯周病）

### 臨床検査

| 検査項目 | 意義 |
|---------|------|
| 血糖値 | 診断の基本となる検査 |
| フルクトサミン | 中期的な血糖コントロールの評価 |
| 尿検査 | 糖尿、ケトン体、尿比重の評価 |
| 電解質 | 脱水、代謝異常の評価 |
| 膵酵素 | 膵炎の併発評価 |
| 肝機能検査 | 肝障害の評価 |

---

## 対症療法

- 適切な水分補給の確保
- 食事管理（適切な量とタイミング）
- 運動管理（過度な運動を避ける）
- 合併症の予防と早期発見
- 定期的なモニタリング
