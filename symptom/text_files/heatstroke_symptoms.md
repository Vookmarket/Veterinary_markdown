# 熱中症の症状

[徴候目次](../index_symptom.md)

## 定義

熱中症による全身性の炎症反応に伴う多様な症状群。高体温を主徴とし、意識障害、循環障害、呼吸障害、消化器症状など多臓器に及ぶ症状を呈する。

---

## 特徴

- 基本的に犬で発症しやすく、猫は発症しにくい
- 高温多湿環境や運動後に発症しやすい
- 短頭種、肥満犬、分厚い被毛の犬種でリスクが高い
- 上部気道閉塞（短頭種気道症候群、喉頭麻痺など）がある犬でリスクが高い
- 循環障害や認知機能不全のある犬でリスクが高い
- 多臓器不全やDICを合併すると予後不良

---

## 鑑別疾患

| 症状 | 鑑別疾患 |
|------|----------|
| 高体温 | 感染症、炎症性疾患、悪性高熱、薬剤性高熱 |
| 意識障害 | 脳炎、脳腫瘍、代謝性脳症、中毒 |
| 呼吸困難 | 肺水腫、肺炎、気道疾患、心不全 |
| 嘔吐・下痢 | 消化器感染症、膵炎、消化管異物 |
| 凝固異常 | 免疫介在性血小板減少症、肝不全、敗血症 |

## 問診

「暑い中で運動や散歩をしましたか？」
→「はい、30分ほど公園で遊ばせていました」

「普段より呼吸が荒くなりましたか？」
→「はい、ハアハアが激しくなってきました」

「ふらつきや意識がもうろうとした様子はありましたか？」
→「はい、歩き方がおかしくなって、呼びかけても反応が鈍くなりました」

「嘔吐や下痢はありましたか？」
→「はい、帰り道で嘔吐しました」

## 検査

### 身体検査

- 体温測定：41℃以上の高体温
- 意識レベルの評価：沈うつ～昏睡
- 粘膜色の評価：紅潮、チアノーゼ
- CRT測定：0.5秒と短縮
- 呼吸状態の評価：パンティング、異常呼吸音
- 脱水の評価：皮膚の弾力性低下
- 神経学的検査：ふらつき、痙攣、振戦

### 臨床検査

| 検査項目 | 異常所見 | 意義 |
|----------|----------|------|
| 血液検査 | Hct↑、TP↑ | 脱水による血液濃縮 |
| 電解質 | Na↑ | パンティングによる水分喪失 |
| 肝酵素 | ALT↑ | 組織障害 |
| 筋酵素 | CK↑ | 筋組織障害 |
| 腎機能 | BUN↑、Cre↑ | 循環不全、腎障害 |
| 凝固系 | 血小板↓、PT/APTT↑ | DIC |
| 血液ガス | 低酸素血症、アシドーシス | 呼吸・循環障害 |
| 心電図 | 不整脈 | 心筋障害 |
| 胸部X線 | 肺水腫、肺出血 | 呼吸器合併症 |

## 対症療法

1. 体温管理
   - ぬるま湯による体表冷却
   - 送風
   - 保冷剤の使用（頚部、肢の下、鼠径部）
   - 目標体温39.4℃

2. 循環管理
   - 輸液療法
   - 血圧モニタリング
   - 尿量モニタリング

3. 呼吸管理
   - 酸素療法
   - 必要に応じて挿管管理

4. 脳保護
   - 頭部挙上
   - グルコース投与
   - 脳浮腫治療

5. 合併症対策
   - 抗菌薬投与
   - 粘膜保護剤
   - DIC対策
