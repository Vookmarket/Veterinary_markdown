# 不整脈症状

[徴候目次](../index_symptom.md)

## 定義

心臓の電気的活動の異常により、心拍のリズム、頻度、または伝導に異常をきたした状態。

---

## 特徴

- 心臓の電気的活動の異常
  - ペースメーカー細胞の異常
  - 刺激伝導系の障害
  - イオンチャネルの機能異常
- 様々な原因で発生
  - 電解質異常（特に高K血症）
  - 心筋疾患
  - 全身疾患の影響
- 重症度は様々
  - 無症状のものから致死的なものまで
- 心電図で特徴的な波形変化を示す

---

## 鑑別疾患

| 疾患 | 特徴 |
|------|------|
| 高K血症 | テント状T波、P波消失、QRS幅増大 |
| 心筋症 | 心拡大、心筋の収縮・拡張異常 |
| 心筋炎 | 炎症による伝導障害 |
| 先天性心疾患 | 構造異常に伴う伝導異常 |
| 薬剤性 | 抗不整脈薬、強心配糖体など |

---

- 「元気はありますか？」→「急に元気がなくなりました」
- 「失神したことはありますか？」→「急に倒れることがあります」

## 検査

### 身体検査

- 心拍数の測定
- 心音聴診：不整脈、雑音の有無
- 脈拍触診：強さ、規則性
- 可視粘膜の色調
- 頸静脈怒張の有無
- 浮腫の有無

### 臨床検査

| 検査項目 | 意義 |
|----------|------|
| 心電図 | 不整脈の種類、重症度評価 |
| 血液検査 | 電解質、特にK値の評価 |
| 心エコー | 心筋の構造・機能評価 |
| 胸部X線 | 心陰影、肺うっ血の評価 |
| ホルター心電図 | 24時間の心電図モニタリング |

心電図所見（高K血症時）：
1. テント状T波
   - 幅が狭く、高い
   - 早期の変化

2. P波の変化
   - 高さの減少
   - 重度では消失
   - 心房の興奮伝導障害

3. QRS波の変化
   - 幅の増加
   - 陰性化
   - 異常な形態
   - 心室の興奮伝導障害

4. その他の不整脈
   - 心房静止
   - 心室粗動
   - 心静止
   - 洞性頻脈
   - 第III度房室ブロック
   - 心室性期外収縮

---

## 対症療法

1. 原因疾患の治療
   - 高K血症：グルコン酸Ca投与、原因対処
   - 心筋疾患：適切な心臓薬物療法
   - その他原因に応じた治療

2. 不整脈自体の治療
   - 抗不整脈薬の投与
   - 徐脈性不整脈：ペースメーカー
   - 頻脈性不整脈：除細動

3. モニタリング
   - 継続的な心電図モニタリング
   - バイタルサインの評価
   - 電解質の定期的評価
