# 前庭症状

[徴候目次](../index_symptom.md)

## 定義

前庭症状は、前庭器官（内耳前庭、前庭神経、前庭核）の機能異常により生じる一連の神経学的症状群である。

---

## 特徴

- 主要な症状
  - 斜頸（頭部を傾ける）
  - 眼振（律動的な眼球運動）
  - 平衡失調
  - 嘔吐（急性期）
  - 円を描くような歩行

- 症状の特徴
  - 急性発症が多い
  - 代償機能により徐々に改善することがある
  - 末梢性と中枢性で症状パターンが異なる

---

## 鑑別疾患

| 分類 | 疾患名 | 特徴的な所見 |
|------|--------|--------------|
| 末梢性 | 特発性前庭障害 | 急性発症、自然改善傾向 |
| | 中耳炎・内耳炎 | 耳の痛み、耳道の異常 |
| | 外傷 | 外傷歴、頭部の損傷 |
| 中枢性 | 脳腫瘍 | 進行性、他の神経症状 |
| | 脳炎 | 発熱、意識状態の変化 |
| | 血管障害 | 急性発症、高齢動物に多い |

---

## 問診

- 「いつから症状が始まりましたか？」
  - 「昨日の夜から急に具合が悪くなり、歩き方がおかしくなりました」

- 「頭を傾ける方向は常に同じですか？」
  - 「はい、常に右側に傾いています」

- 「嘔吐はありますか？」
  - 「最初の日は2回ほど嘔吐しましたが、今は落ち着いています」

- 「耳の病気や外傷の既往はありますか？」
  - 「以前から耳の掻痒感があり、慢性的な耳の問題がありました」

---

## 検査

### 身体検査

- 意識状態の評価
- 頭位と斜頸の方向の確認
- 眼振の評価
  - 方向
  - 性質（水平、垂直、回旋性）
- 歩行評価
- 姿勢反応テスト
- 脳神経検査

### 臨床検査

| 検査項目 | 目的 | 備考 |
|----------|------|------|
| 耳道検査 | 中耳炎の評価 | 耳垢、炎症、腫瘤の確認 |
| 神経学的検査 | 末梢性vs中枢性の鑑別 | 意識、姿勢反応、脳神経 |
| MRI/CT | 中枢性病変の評価 | 腫瘍、炎症、血管障害の確認 |
| 血液検査 | 全身状態の評価 | 感染、炎症マーカー |

---

## 対症療法

- 制吐剤：嘔吐の管理
- 抗めまい薬：前庭症状の緩和
- 環境管理：安全な空間の確保、スリップ防止
- リハビリテーション：バランス訓練、歩行訓練
