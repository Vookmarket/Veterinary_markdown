# 咳

[徴候目次](../index_symptom.md)

## 定義

咳は身体の防御メカニズムの一つで、「咳反射」と呼ばれる。身体にとって有害な物質（異物、病原体、気道からの過剰な分泌物など）を取り込まないようにするための反射機構である。

---

## 特徴

### 解剖学的特徴
- 咳受容体は喉頭・気管・気管支にのみ存在し、細気管支や肺胞には存在しない
- 咳反射の特徴：
  - 咳の出始めや直前に勢いよく息を吸い込むタイミングがある
  - 気管支（やや下の方）への刺激で出やすい
- 呼気反射との違い：
  - 呼気反射は勢いよく息を吸い込むタイミングはなく、いきなり息を吐く
  - 喉頭（かなり上の方）への刺激で出やすい

### 動物種による違い
- 犬：一般的な臨床症状で、様々な原因（気道疾患、心疾患など）で発現
- 猫：
  - まれな臨床症状
  - 心臓由来の咳は極めて稀少
  - 咳は気管気管支疾患にかなり特異的
  - 嘔吐や毛玉を吐き出す動作と誤認されることがある

---

## 鑑別疾患

| 分類 | 疾患名 | 特徴 |
|------|--------|------|
| 気道の構造異常 | 気管虚脱・気管支虚脱 | 犬で最も多い。気道がつぶれることで物理的な刺激となる |
| 気道の炎症 | 猫喘息 | 好酸球性炎症。猫の気管支は犬より収縮しやすい |
| | 慢性気管支炎 | 犬でみられる |
| 感染症 | ケンネルコフ | 犬伝染性喉頭気管炎。複数の病原体が関与 |
| 循環器疾患 | MMVD | 左心房拡大による気管支圧迫の可能性 |
| その他 | 異物 | 気道内異物 |
| | 寄生虫症 | フィラリア症など |
| | 腫瘍 | 喉頭～気管支の腫瘍 |

## 問診

### 共通の質問
- 「いつから咳が出ていますか？」
- 「咳の性状はどのようですか？（乾いた咳、湿った咳、発作的な咳など）」
- 「1日のうちでいつ咳が多いですか？（運動時、夜間など）」
- 「他の症状はありますか？（食欲、元気、呼吸困難など）」

### 犬の場合
- 「ペットホテルやドッグランなどの利用歴はありますか？」
- 「心疾患の既往はありますか？」

### 猫の場合
- 「嘔吐や毛玉を吐き出すような動作と区別できますか？」
- 「環境の変化（新しいスプレー、タバコ、ほこりなど）はありましたか？」
- 「ストレスを感じるような出来事はありましたか？」

## 検査

### 身体検査

- 呼吸状態の観察（呼吸数、呼吸パターン）
- 気道聴診（異常呼吸音の有無）
- 心臓聴診（心雑音の有無）
- 体温測定
- 気道への圧迫試験

### 臨床検査

| 検査 | 目的 | 特記事項 |
|------|------|----------|
| 胸部X線検査 | 気管虚脱、心拡大、肺水腫、腫瘍などの評価 | 猫では肺の過膨張の評価も重要 |
| 気管支内視鏡検査 | 気管虚脱のグレード評価、異物・腫瘍の確認 | 猫の喘息クリーゼ時は禁忌 |
| 気管支肺胞洗浄液検査 | 炎症性細胞の評価 | 猫の気道疾患の鑑別に重要 |
| 血液検査 | 炎症マーカー、感染症検査 | 猫では好酸球数の評価も重要 |
| 心エコー検査 | 心疾患の評価 | 猫では心原性咳は稀少 |
| 気道反応性検査 | 気道過敏性の評価 | 猫喘息の診断に有用 |

## 対症療法

1. 環境改善
   - 空気清浄化（タバコ、ホコリ、スプレー類の回避）
   - 適度な運動（短時間のダッシュを避け、ゆっくり長めの散歩を推奨）
   - ハーネスの使用（首輪による気管圧迫を避ける）
   - ダイエット（必要な場合）
   - 加湿（分泌物の排出改善）

2. 薬物療法
   - 咳止め：ブトルファノール、マロピタント
   - 気管支拡張薬：サルブタモール、テオフィリン、アミノフィリン、テルブタリン
   - 吸入ステロイド：フルティカゾン
   - 粘液溶解剤：アセチルシステイン、アンブロキソール、ブロムヘキシン
