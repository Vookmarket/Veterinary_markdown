# 多飲多尿

[徴候目次](../index_symptom.md)

## 定義

多飲(Polydipsia)は1日の飲水量が異常に増加する状態、多尿(Polyuria)は1日の尿量が異常に増加する状態を指します。

---

## 特徴

- 正常な飲水量は体重1kgあたり1日約50ml
- 多飲は体重1kgあたり1日100ml以上の飲水量
- 多尿は尿比重の低下（犬<1.015、猫<1.020）を伴う
- 多くの場合、多飲と多尿は同時に発現
- 飼い主が最初に気付く症状の一つ

---

## 鑑別疾患

| 疾患カテゴリ | 具体的な疾患 |
|------------|-------------|
| 腎臓疾患 | 慢性腎臓病、急性腎障害 |
| 内分泌疾患 | 糖尿病、クッシング症候群、副腎皮質機能低下症 |
| 肝臓疾患 | 肝不全 |
| 電解質異常 | 高カルシウム血症 |
| その他 | 心因性多飲症、薬剤性（ステロイド、利尿薬） |

---

## 問診

- 「水を飲む量が増えましたか？」
  「はい、水bowl（容器）を1日に何度も取り替えるようになりました」
- 「トイレの回数は増えましたか？」
  「はい、以前の2倍くらいになりました」
- 「いつ頃から症状に気付きましたか？」
  「約2週間前からです」
- 「その他の症状はありますか？」
  「食欲が落ちてきて、少し痩せてきました」

---

## 検査

### 身体検査
- 脱水の有無の確認
- 体重測定
- 体型（肥満/痩せ）の評価
- 腹部触診（腎臓、肝臓の大きさ）

### 臨床検査

| 検査カテゴリ | 検査項目 | 目的 |
|------------|---------|------|
| 血液検査 | BUN、Cre、電解質 | 腎機能評価 |
| | 血糖値 | 糖尿病の評価 |
| | 肝酵素 | 肝機能評価 |
| 尿検査 | 比重 | 濃縮力評価 |
| | 糖、蛋白 | 腎機能、代謝異常評価 |
| 内分泌検査 | コルチゾール | クッシング症候群の評価 |
| 画像検査 | レントゲン、エコー | 腎臓、肝臓の評価 |

---

## 対症療法

- 原疾患の治療が基本
- 水分制限は原則として行わない
- 脱水予防が重要
- 必要に応じて輸液療法
