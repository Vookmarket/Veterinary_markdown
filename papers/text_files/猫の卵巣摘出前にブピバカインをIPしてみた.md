# 猫の卵巣摘出前のブピバカイン腹腔内投与による術中鎮痛効果の評価：ランダム化臨床試験

[論文目次](../index_papers.md)

## Abstract

卵巣摘出術を受ける猫において、術前の超音波ガイド下腹腔内ブピバカイン投与が術中・術後の疼痛管理に与える効果を評価した。47頭の雌猫を対象とした前向きランダム化二重盲検プラセボ対照試験を実施。術中の自律神経反応は両群で同様に認められ、イソフルラン要求量への影響は限定的であった。術後疼痛管理においてNSAIDsと比較して有意な利点は認められなかった。

## 背景

- 効果的な疼痛管理は患者ケアに不可欠
- 術中・術後の疼痛は慢性痛のリスク因子
- 先制鎮痛は中枢性感作を予防する目的で実施
- 局所麻酔は多様式鎮痛の重要な要素
- 超音波ガイドにより局所麻酔の正確性と安全性が向上

## Methods

### 材料

- 47頭の健康な雌猫
- 0.25%ブピバカイン vs 生理食塩水（0.4 ml/kg/片側）
- 超音波装置（6-13MHz リニアプローブ）
- 22G 1.5インチスパイナル針

### 手順

1. 標準的な麻酔プロトコル実施
2. 超音波ガイド下で腹腔内投与
3. 卵巣摘出術実施
4. 術中評価：心拍数、呼吸数、収縮期血圧、気化器設定値
5. 術後評価：Glasgow Composite Measure Pain Scale

### 統計手法

- 二元配置分散分析とŠidákの多重比較検定
- Gehan-Breslow-Wilcoxon検定
- 有意水準：p < 0.05

## Conclusion

- 手術時間：両群で有意差なし
- 術中の自律神経反応：両群で同様に上昇
- イソフルラン要求量：US-IPLA群でわずかに低下
- レスキュー鎮痛必要症例：両群で有意差なし

## Discussion

- 術中の自律神経反応抑制効果は限定的
- イソフルラン要求量への影響も最小限
- NSAIDsと比較して術後疼痛管理に有意な利点なし
- 組織損傷が大きい場合、NSAIDsとの併用が有用かもしれない

### 限界

- 教育実習での実施による手技の変動
- 腹腔内での薬剤希釈の可能性
- 短期的な評価のみ
- 卵巣摘出術のみの評価

### まとめ

- 術前腹腔内ブピバカイン投与は術中の疼痛反応を有意に抑制しない
- 術後疼痛管理においてNSAIDsと同等の効果
- 用量、濃度、容量の最適化が必要
