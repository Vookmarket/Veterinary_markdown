# 犬と猫の病態生理_高血圧

[論文目次](../index_papers.md)

## Abstruct

犬猫における全身性高血圧の病態生理、診断、治療について解説した総説。特に血圧のコントロールメカニズム、高血圧の原因疾患、標的臓器障害について詳細に記述している。

## 背景

- 犬猫の高血圧は主に二次性高血圧として発症
- 高齢動物で発症率が高い
- 標的臓器障害（TOD）の早期発見が重要

## Conclusion

1. 疫学データ
   - 犬の13%（7-8頭に1頭）が罹患
   - 猫の19.5%（5頭に1頭）が罹患
   - 高齢（>9歳）で診断されやすい

2. 併発症と高血圧の発生率
   犬：
   - 慢性腎臓病（~90%）
   - 急性腎障害（~90%）
   - クッシング症候群（~80%）
   - 糖尿病（~70%弱）
   - 褐色細胞腫（~90%弱）

   猫：
   - 慢性腎臓病（~70%）
   - 甲状腺機能亢進症（~90%）
   - 原発性高アルドステロン症（~100%）
   - 糖尿病（~20%）
   - クッシング症候群（~20%）

3. 血圧値による分類
   - 正常血圧：<140mmHg（TODリスク最小限）
   - 前高血圧：140-159mmHg（TODリスク低）
   - 高血圧：160-179mmHg（TODリスク中）
   - 重度高血圧：≥180mmHg（TODリスク高）

## Discussion

1. 客観的に明らかなこと
   - 犬猫の高血圧は主に二次性
   - 腎疾患が最も多い原因疾患
   - TODは4つの主要臓器（眼、腎臓、心血管系、脳脊髄）に発生

2. 著者の考察
   - 血圧測定の正確性が重要
   - 環境性高血圧との鑑別が必要
   - TODがある場合は早期治療が必要

3. 著者の提言
   - 高齢動物の定期的な血圧測定
   - 基礎疾患のスクリーニング
   - TODの早期発見のための定期検査

### 限界

- 血圧測定の環境による変動
- 基礎疾患の見逃しの可能性
- 治療効果の個体差

### まとめ

1. 血圧コントロールの重要性
2. 基礎疾患の管理の必要性
3. TODの予防と早期発見の重要性
4. 適切な血圧測定の必要性
